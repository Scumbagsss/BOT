# Private source policy

The full DeadCity Bot source code is maintained in a private repository.

## Public here

- project description;
- high-level architecture;
- feature overview;
- isolated code excerpts;
- sanitized screenshots/demos added by the author;
- portfolio/evaluation documentation.

## Kept private

- executable application entry point;
- complete Discord cogs and services;
- production configuration;
- tokens and API credentials;
- Discord/guild/channel/role/user IDs;
- production database and logs;
- full SQL schema;
- anti-abuse and detection algorithms;
- internal thresholds and correlation rules;
- deployment/operations details.

This split allows potential collaborators or clients to evaluate the project without receiving a redistributable copy of the product.
