# Feature overview

This is a portfolio-level description of functionality implemented in the private production project.

| Area | What it does | Public source? |
|---|---|---|
| Server monitoring | Tracks availability, players, queue and server metadata | Architecture only |
| Ticket system | Request categories, staff actions, archiving and transcripts | No |
| Audit logging | Discord member/message/voice/role/nickname events | No |
| Role prefixes | Applies configurable nickname prefixes from roles | No |
| Nickname workflow | User request + staff approval/rejection | No |
| Temporary radios | Creates and cleans temporary voice channels | No |
| Faction workflow | Reservation and community-management interactions | No |
| Priority access | Configurable priority/member workflow | No |
| Feedback | Structured user feedback flow | No |
| Spawn monitoring | Detects configured suspicious item/event patterns | No |
| Abuse monitoring | Staff alerts for suspicious administrative activity | No |
| Duplicate-event analysis | Parsing, case storage and confidence-based analysis | No |
| Reporting | Generates staff-facing data and visual output | Selected examples only |

## Notes

The absence of source for a feature is intentional. The purpose of this repository is to demonstrate project scope, design and coding style without distributing a deployable clone of the production system.
