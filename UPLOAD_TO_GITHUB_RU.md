# Как загрузить showcase на GitHub

## Рекомендуемое имя репозитория

`deadcity-discord-bot`

или, если хочешь сразу подчеркнуть формат:

`deadcity-bot-showcase`

## Description

`Private production Discord automation system — architecture, features and selected Python excerpts`

## Настройки

- Visibility: **Public**
- Не добавляй при создании README / .gitignore / License: они уже есть в архиве.

## Загрузка через сайт GitHub

1. Создай пустой Public repository.
2. Нажми **uploading an existing file** / **Add file -> Upload files**.
3. Распакуй ZIP локально.
4. Перетащи **содержимое папки**, а не сам ZIP.
5. Commit message: `Publish portfolio showcase`.
6. Нажми **Commit changes**.

## После загрузки

Добавь Topics:

`python`, `discord-bot`, `discord-py`, `automation`, `asyncio`, `portfolio`, `dayz`

Затем закрепи репозиторий на профиле через **Customize your pins**.

## Важно

Этот showcase специально не запускается как бот. Не добавляй в него настоящий `bot.py`, полный production source, токены, рабочий config или базы данных.
