# Security Policy

This repository is a non-runnable portfolio showcase and must never contain production credentials or private operational data.

Do not commit:

- Discord bot tokens;
- API keys;
- webhook URLs;
- `.env` or production config files;
- database files;
- logs/backups;
- private Discord IDs or internal server information;
- production detector rules/thresholds.

If a credential has ever been exposed outside the intended private environment, revoke/rotate it before continuing to use it.
